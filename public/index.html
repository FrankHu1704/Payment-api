Como funciona

3 passos pra começar a receber

1

Crie sua conta e gere uma chave de API

Cadastre seu negócio no dashboard e crie um par de chaves (pública/secreta) pra autenticar suas chamadas.

2

Crie uma sessão de checkout

Sua aplicação chama a API com o valor da cobrança e recebe de volta um link de pagamento pronto.

3

Receba o pagamento e a notificação

O cliente paga pelo M-Pesa no link, e você recebe a confirmação instantânea via webhook.

Simples de integrar

Uma chamada cria a sessão de checkout. O resto — USSD push, confirmação, webhook — a plataforma cuida.

Pegar minha chave de API

// criar uma sessão de checkout
const res = await fetch('https://payment-api-blond.vercel.app/api/checkout-sessions', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_live_...',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    amount: 150,
    reference: 'PEDIDO-1024',
    successUrl: 'https://sualoja.co.mz/obrigado'
  })
});

const { url } = await res.json();
// -> manda "url" pro seu cliente pagar
